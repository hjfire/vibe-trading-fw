# Vibe-Trading 使用说明

> 面向日常使用者。讲「打开浏览器之后该点哪里、输什么、会看到什么」。
> 不讲代码结构、不改配置文件的原理、同步上游的冲突处理——那些记在仓库根的 `项目档案.md` 里。
>
> 章节按「先能跑起来 → 再认路 → 再逐个页面 → 最后常见问题」排列。只想干一件事的人，直接看下面第 1 节。

---

## 1 三十秒上手

1. 双击项目文件夹里的 **`start.bat`**。
2. 会弹出**两个黑色命令行窗口**（后端、前端），别关它们。
3. 浏览器打开 **http://localhost:5899** 。
4. 左侧第一栏点 **智能体**，在最下面的输入框里说一句人话，例如：

   ```text
   用 600519.SH 做 2024 年全年回测，双均线策略，和沪深300比一下
   ```

   按 **Enter** 送出（**Shift+Enter** 是换行，不会发送）。
5. 想看 K 线、画线、自己写指标 → 左侧点 **专业图表**。想让价格到某个位置时通知你 → 左侧点 **Alerts**。

用完了：把那两个命令行窗口各自关掉，服务就停了。

**这一份说明在哪看**：左侧栏最下面的 **使用说明**（或地址栏输入 `http://localhost:5899/help`）。这份文档是纯文本文件，也可以用记事本打开 `frontend/public/usage-guide.md` 直接读。

---

## 2 启动、关闭与两个端口

`start.bat` 一次拉起两个服务：

| 服务 | 地址 | 干什么 |
|---|---|---|
| 后端 API | http://127.0.0.1:8000 | 真正干活的：跑智能体、取行情、回测、报警轮询 |
| 前端界面 | http://localhost:5899 | 你看到的网页（开发模式，改前端代码会热更新） |

两个都要活着，缺一不可。**关掉窗口 = 停掉服务**；没有托盘图标，也没有后台守护。

日常请固定用 **http://localhost:5899**。

另外存在一个 **http://127.0.0.1:8000** ：它服务的是「上一次前端构建产物」（`frontend/dist`）。
- 优点是少一个进程，且和正式部署一致；
- 缺点是**它不会自动更新**——前端代码改过之后，得在 `frontend` 目录跑一次 `npm run build`，`:8000` 才会变，而 `:5899` 一直是最新的。
- 如果 `frontend/dist` 不存在，`:8000` 只有接口没有页面。

**建议**：把 `:5899` 存成浏览器书签，作为唯一入口。

### 关掉之后仍在跑的东西

- 后端窗口里如果打印过 `FutuOpenD` 相关连接，那只是**它去连你的** `:11111`，不会反过来拖累你。
- 定时任务、报警轮询都是**后端进程内的线程**：后端窗口一关，全部暂停（见 §16、§19）。

## 3 每天开机后的固定动作

1. （要交易行情/富途数据时）先启动 **FutuOpenD** 客户端并登录，等它进入「就绪」窗口。没开也不会报错，只是自动改用公开行情源，速度较慢、字段较少（见 §18）。
2. 双击 **`start.bat`**。
3. 打开 http://localhost:5899。
4. 想更新到官方最新版时，双击 **`sync.bat`**。它等价于 `git checkout main` + `git pull`；拉完之后**重启 `start.bat`** 才生效。
   - 报「切换 main 分支失败，可能有未保存的改动」⇒ 说明有文件没提交或没还原，先处理再拉。
   - 每天北京时间 20:00 GitHub 会自动把官方更新合进你的仓库，所以 `sync.bat` 一般只是把它同步到本机。

## 4 第一次使用前要配的东西

### 4.1 大模型（必须）

不配模型，智能体只会报错，其余功能（图表、画线、指标、报警行情条件）照常可用。

两条路，任选其一：

- **界面上配**：左侧 **设置** → `LLM 后端`：选提供商、填模型名与 API Key、必要时改 `基础 URL` → 点 **保存**（会写回 `agent/.env`）。
- **文件里配**：编辑 `agent/.env`，把 `LANGCHAIN_PROVIDER`、`LANGCHAIN_MODEL_NAME`、对应的 `*_API_KEY` 填好，然后重启后端窗口。

两个建议：

- **温度**保持低位（界面上写着「建议保持在 0–0.2」）。金融计算要的是可复现，不是创造性。
- **超时（秒）**默认 120；跑大回测或长报告时如果经常中断，把它调大。

### 4.2 本机不需要密钥

后端有「回环信任」：当 `agent/.env` 里**没有**设置 `API_AUTH_KEY` 时，来自本机的请求直接放行——你打开 `:5899` 不会遇到任何登录框。

一旦设置了 `API_AUTH_KEY`（比如要把服务暴露到局域网），所有接口包括 **设置页** 都要求出示密钥：此时去 **设置 → API 认证密钥** 输一次，浏览器会记住（存在本地，不在 URL 里）。

**不要**为了省事把 `:8000` 直接开到公网：那是另一套部署问题，需要先配密钥。

### 4.3 可选增强

| 项目 | 怎么开 | 换来什么 |
|---|---|---|
| FutuOpenD 行情 | 装好富途客户端并登录，本机 `127.0.0.1:11111` | A股/港股/美股自动优先走它：更快、字段更全、能拿盘口 |
| 行情缓存 | `agent/.env` 里 `VIBE_TRADING_DATA_CACHE=true`（本机已开） | 省富途 K 线额度，重复看同一标的秒开 |
| 券商只读连接 | **持仓 → 管理账户** | 多账户合并估值、导出 CSV、给报警提供持仓/账户条件 |
| IM 推送通道 | 见 §16.4 | 报警能发到 QQ / Telegram / 钉钉 / 飞书 等 |
| Tushare / Baostock | **设置 → 数据源** 里配 Token | A 股历史数据的备用来源 |

## 6 智能体对话（`/`）

这是唯一必须「会说话」的页面：你用自然语言描述研究目标，它去调工具（取数、写策略、回测、算指标、画图）。

### 6.1 输入框能做的事

- **Enter** 送出，**Shift+Enter** 换行（框下面写着 `Enter 送出 · Shift+Enter 换行`）。
- **上传文件**（回形针）：券商成交 CSV、财报 PDF 等。注意提示 `不允许上传可执行文件和压缩包`——只收文档与数据。
- **启动智能体团队**：把一个话题交给多角色辩论/流水线（多空辩论、量化工作台等预设）。
- **模型与推理强度**：输入框上方可临时切换本次用的模型和推理强度，不改全局设置。
- **导出对话**、**停止生成**（跑偏了立刻止损，提示 `正在停止…`）。
- 输入框示例提示词：`例如：为 000001.SZ 创建双均线交叉策略，回测 2024 年`。

### 6.2 首次进入的推荐用法

空白页上有一排**示例卡片**，按类别分组：A股回测、研究与分析、智能体团队、文档与网络研究、交易日志、交易连接器、影子账户、价值投资。点一张卡片会把写好的提示词填进输入框——**这是学会「怎么跟它说话」最快的路径**，因为卡片里的提示词都是能直接跑出结果的完整句式。

### 6.3 目标（Goal）机制

对话右上角可以**新建研究目标**：填「目标 / 达成标准 / 证据」三件事。之后这一轮工作会围绕目标推进，右侧 **目标** 面板显示进度与近期证据，可随时 继续 / 编辑 / 取消目标。适合「今天必须把这件事查清楚」型任务；随手问一句就不需要用。

### 6.4 结果去哪看

一次运行结束后，界面上会出现运行卡片与链接，点进 **`/runs/<运行编号>`** 看完整报告（净值曲线、回撤、交易明细、生成的策略代码、审计日志）。所有跑过的运行都会留在 **报告** 页，不会丢。

## 7 交易监控（`/runtime`）

副标题写得很清楚：`只读状态` —— 这一页**不会**授权连接器、不会启停执行程序、不会提交或撤单、不会修改交易授权。

看三件事：

- **全局熔断**：`正常` / `已熔断`。熔断是总闸。
- **券商** 列表：每个连接器档案是否 `已授权`、执行程序 `存活`/`已停止`、`最后心跳`。
- 若显示 `未报告任何连接器档案` ⇒ 你还没配任何券商连接，这一页本来就没东西可看，不是故障。

---

## 8 定时任务（`/scheduled`）

让一段提示词按周期自动跑，产出还是进 **报告** 页。

填写：

1. **研究提示词**（必填），例：`盘前扫描：按昨日异常成交量排名并总结隔夜新闻`
2. **运行节奏**：
   - `每天定时`：选 本地时间 `HH:MM` + 运行日（工作日 / 每天）
   - `高级（cron 或间隔）`：5 字段 cron（分 时 日 月 星期）或以毫秒为单位的间隔
3. **时区**：按你选的时区求值，夏令时切换后节奏不变。

点 **创建定时任务**。列表里能看到每条的节奏（`每天 08:30` / `每周…` / `每 …`）与状态（`待运行` 等）。

**必须知道的一条**：页面上那行小字 `仅当服务端启用 VIBE_TRADING_ENABLE_SCHEDULER 时才会执行。` 意思是——**后端窗口关着，到点也没人跑**。想真正无人值守，得让后端常驻（或用 Docker 部署，见 §20）。

## 9 报告、运行详情与策略对比

### 9.1 报告（`/reports`）= 历史回测档案柜

- 搜索框：按 运行 ID / 提示词 / 标的 / 状态 过滤
- 过滤：全部状态、开始日期、结束日期
- 排序：最新优先 / 最早优先 / 收益率从高到低 / 夏普从高到低
- 每行显示收益率、夏普，右侧 **完整报告** 进详情、**对比** 加入比较
- 空态 `先在智能体中创建一次回测，然后回到这里查看。` ⇒ 正常现象，你还没跑过

### 9.2 运行详情（`/runs/<编号>`）

一次运行的全部产物：净值与回撤曲线、指标卡、交易明细、因子/验证面板、生成的策略代码、审计日志。数字旁边若有疑问，看 **审计/验证** 标签——每次运行都留了底。

### 9.3 策略对比（`/compare`）

从报告页选两次运行后进此页，左右两栏 + 差值列：总收益率、年化、夏普、卡尔马、索提诺、最大回撤、波动率、胜率、盈亏比、平均盈利/亏损、交易次数、最大连亏、持仓时间、平均持仓天数。**用它判断「改了参数到底有没有变好」，别看单条曲线的顺眼程度。**

## 10 持仓（`/portfolio`）

标签写着 `本机只读 · 多账户`：它只**读取**你已启用的只读连接，汇总成一份估值。

- 顶部指标：**总资产**、**今日资产变化**（含行情波动与出入金）、**估值覆盖率**（`已定价 N · 现金 M`）、**最后一次完整更新**
- 若显示 `N 个账户读取失败，未计入该合计` ⇒ 合计是**扣掉失败账户**后的数，别当成全貌
- 汇率行：`USD/CNY x.xxxx · 实时汇率` 或 `· 缓存汇率`
- 按钮：**管理账户**（添加/重连只读连接）、**刷新全部账户**、**导出 CSV**
- 空态 `还没有持仓快照` → 点 **添加账户**

重连券商时若提示 `等待浏览器授权超时，请重新连接并及时完成券商授权`：授权页要你点完，别放着不管。

## 11 Alpha 因子库（`/alpha-zoo`）

现成量化因子的货架：来自 Qlib、Kakushadze 101、GTJA 191、学术异象、PIT 安全基本面 五个因子库。

- 顶部一句 `N 个预构建量化 Alpha，覆盖 5 个因子库`
- 筛选：搜索（按 ID 或昵称）、因子库、主题、标的池
- 点任意因子 → 看**公式**与源码、元数据（频率、衰减周期、最小预热 K 线数、是否需行业分类、模块路径）
- **运行基准测试**：在整个市场/时间段上给整库打分（可设 衰减天数）
- 勾选多个 → **对比**（`/alpha-zoo/compare`）

用法建议：把这里的因子当「现成零件」，让智能体用某个因子去回测你的标的，比自己从头编因子快得多。

## 12 期权实验室（`/options`）

`策略构建器、到期损益、标的价 × 隐含波动率情景、组合希腊值与美股实时期权链。`

- **预设策略** 一键摆出常见腿（买入看涨、价差、跨式…），也可自己加腿
- 到期损益图、盈亏平衡点
- 标的价 × IV 的情景矩阵
- 组合希腊值（Delta/Gamma/Theta/Vega）
- 美股实时期权链

页面底部固定一句免责声明：`仅供研究参考。理论定价与情景结果为模型估算，不构成投资建议。` —— 这里的所有数字都是模型算的。

## 13 相关性矩阵（`/correlation`）

- **资产代码**：逗号分隔，提示写得很明白 `逗号分隔的标的代码，如 BTC-USDT,ETH-USDT,AAPL,SPY`
- **窗口（天）**、**方法**（皮尔逊 / 斯皮尔曼秩相关）→ 点 **计算**
- 下方 **相关性状态时间线**：`边密度 + 滞回状态机的时间序列 — 描述性风险背景，并非交易信号`

注意：**这里的输入框没有代码联想**（有意为之）。它是「一次粘一串」的用法，换成下拉选择反而更慢；要单个找代码，去 **专业图表** 或 **Alerts** 的标的框。

## 14 设置（`/settings`）

一个页面五块内容，全部点 **保存** 才生效：

1. **LLM 后端**：提供商、模型名称、基础 URL、温度、超时、最大重试、推理强度。可勾 `使用默认模型` / `使用默认 URL` 回落到内置默认。
2. **数据源**：tushare（需 `TUSHARE_TOKEN`）、baostock（无需密钥，走 TCP）等的 `已安装/未安装` 与 `Token 已配置/未设置` 状态。
3. **数据源优先级**：按市场（A股 / 港股 / 美股 / 加密 / 外汇…）排尝试顺序。说明写得很准：`控制智能体自动取数时各市场数据源的尝试顺序；显式指定的数据源不受影响。`
   - 若你在 `agent/.env` 里手写过 `MARKET_DATA_ORDER_*`，且和新默认链不兼容，后端会**告警并保留默认链**；此时在这个卡片里重新保存一次即可。
4. **IM 通道**：一张状态表（每个通道 `已启用/已禁用`、`已加载/未加载`、`恢复方式`）+ **启动通道** / **停止通道** / **刷新**。缺依赖的通道会直接告诉你装什么的命令（形如 `pip install 'vibe-trading-ai[telegram]'`）。
5. **API 认证密钥**：只在后端设了 `API_AUTH_KEY` 时才需要在这里填一次。

## 15 专业图表（`/pro-chart`）

本地自建的那套图，也是这个项目相对官方多出来的最大一块。红涨绿跌，数据走本机接口。

### 15.1 选标的：直接打代码或名字

顶部标的框支持**输入联想**。打前几位就跳候选，约 35 毫秒：

| 你打 | 会出 |
|---|---|
| `600` | 浦发银行 `600000.SH`、`600004` … |
| `茅台` | 贵州茅台 `600519.SH` |
| `aapl` | `AAPL.US` … |
| `00700` | 腾讯控股 `00700.HK` |
| `brk` | `BRK.B.US`（带点的美股也认） |
| `600519.SH` | 原样命中，不会再被顶替 |

**键盘**：`↑` `↓` 在候选里移动，`Enter` 提交，`Esc` 关下拉。

**Enter 的三种行为**（这条最容易踩，说清楚）：

1. 你打的还不是一个**完整可路由**的代码（比如裸 `00700`，缺市场后缀），而下拉里有候选 → **取第一条**。因为裸码在存进自选/会话/报警规则后会变成难认的形态。
2. 已经是完整代码，或加密/外汇这种名册里根本没有的（`BTC-USDT`、`EURUSD.FX`）→ **原样提交**你打的。
3. 你手动 `↑` 高亮了最后那行 `使用 <你输入的内容>` → **永远尊重你的选择**。

**没匹配上时**会显示 `无匹配，可直接输入完整代码` —— 它只是提示，输入框依然可用，敲完整代码回车即可。

**名册第一次准备时**（后端刚重启、缓存过期或你换了机器）会显示 `代码库首次构建中…`，此时列表还没内容但**不报错**，十几秒后再打字就有。名册约 3.2 万行（沪深京 + 港 + 美），后台每天自动保鲜一次；想立刻强制重建，浏览器直接访问：

```text
http://127.0.0.1:8000/market/symbols?q=maotai&refresh=1
```

看到 `"status": "warming"` 就说明正在后台重建，几十秒后回来即可。

同样的联想出现在：**专业图表顶栏**、**自选列表的搜索添加**、**TV 图表**、**Alerts 的规则标的框**。

### 15.2 周期、K 线与分时

- 周期按钮八档：`1分 / 5分 / 15分 / 30分 / 60分 / 日线 / 周线 / 月线`
- **分钟线全市场可用**：`.SH / .SZ / .HK / .US` 四类都支持，**优先取 FutuOpenD**（得开着它）。A 股在富途未应答时自动落回新浪，所以你看到的数据源不一定一样。
- 其余标的（加密货币、英股、指数、外汇）除 `日线 / 周线 / 月线` 外仍然灰掉，提示写的是 `分钟线需 FutuOpenD（支持 .SH/.SZ/.HK/.US）`——这四类以外确实没有分钟级数据源，不是坏了。
- **分钟线只给前复权（qfq）**：富途只有一个口径。专业图表默认就是 qfq，所以感知不到；但你在 Alerts 里把 `adjust` 改成 `none`/`hfq` 时，A 股会改走新浪，港美股则直接报错。
- **周线 / 月线是把日线合并出来的，不是问数据源要周线**：按**自然周（ISO 周）/ 自然月**分组，开=组内第一个交易日的开，高/低=组内极值，收=最后一个交易日的收，量=求和；一根线横坐标落在它那一周/月的**第一个交易日**上。为什么不直接问源要：① 覆盖面——凡日线能画的标的周月都能画（加密、外汇、指数都没有源生周线）；② 复权口径唯一——源生周线自带一套复权基准，「前复权」就会在两个按钮上意味着两件事；③ 翻页游标干净——合并线的时间戳就是组边界，往左翻不会把一周劈成两截。状态行会带 `+1W` / `+1M` 后缀，明说这些线是折出来的。
- **整周休市就没有那一周的线**（春节、国庆黄金周常出现一周空档，相邻两根相隔 14 天甚至更久），这是对的，不是缺数据。周月的**可翻深度就等于日线的可翻深度**（同一份数据，不会更深）：本机实测 2026-09-10 —— A 股约 20 年（茅台到 2006-08，富途链封顶）、美股约 20 年、腾讯等港股约 6.6 年（公开链只到 2019-11）、加密货币就是它日线的全部历史。翻到头图就停住，不会转圈。
- **往左拖 = 加载更早的 K 线**，到最左边会停住；图会自动补一页历史（约 500 根，日线是 500 天、周线约 10 年、月线约 40 年）。加载位置有明确提示（`offRight` 类文案），不会静默把你正在看的画面甩走。分钟线往回翻只能翻到富途额度给的那几天（约一周）。

**分时（工具栏最左边的 `分时` 按钮）**

- 它是**一种视图，不多占一档周期**。点亮后画的是最近一个交易日的**分钟折线 + 均价线 + 昨收线**（券商那种分时），底部状态条同时给出 `分时 2026-09-04 · 昨收 440.00 · +1.00%` 这样一句话（休市时就是上一个交易日）。鼠标十字线的标题里周期会写成 `1分钟`，不是光一个 `1`。
- **一屏放得下整天**：进入分时时按窗口宽度重排每根分钟线的间距，收盘后一个交易日正好铺满；拉动窗口大小会重新铺一次。一根分钟线**最宽只给 50px**（图表库的硬上限），所以盘中刚开盘的那阵子根数太少、铺不满一屏：这时折线**始终从左边 09:30 那一侧开始画**，空出来的一段留在**右边**，代表今天还没走到的那几分钟——右侧刻度里出现尚未到达的时间是分时的正常样子，不是数据缺了。只有窗口太窄、连最小间距都放不下整天时才会退回可拖动——宁可挤，也不会把线画到画面外。
- 只有 `.SH / .SZ / .HK / .US` 能点亮，其它标的按钮是灰的——和分钟线同一个前提（要开着 FutuOpenD）。
- **和周期按钮互斥**：分时亮着时八个周期按钮都不亮（它们说的是蜡烛的周期，不是折线的）；点任一个周期按钮就回 K 线，而且回到你**原来那一档**，不会把你扔到 1 分钟蜡烛上。再点一次 `分时` 也是回 K 线。
- **不能往左拖**（故意）：分时一次取数就够，翻页会逐次吃富途额度，而上一天的分钟线不属于「分时」这张图。要看历史请点周期按钮。
- **均价是成交量加权的估算，不是交易所公布的 VWAP**：本项目的分钟线接口只回传开高低收与成交量这几列（富途原始返回里是带成交额的，这条链路没有把它带过来），所以用 Σ(收盘×量)/Σ(量) 近似。某一刻成交量全是 0 时退化为累计均价，不会把线钉在 0 上把纵轴拉塌。
- **昨收可能算不出来**，那时状态条只写 `昨收未知`，不会补一个 `+0.00%` 糊弄你：取回的时间窗口里没够到上一个交易日的最后一根就会这样（额度边界、停牌、开盘前）。这时图上那条昨收虚线也**一并没有**——不拿一个猜出来的高度骗眼睛。
- **昨收那条灰色虚线就是你该盯着的零线**。没有它，涨 3% 的一天和跌 3% 的一天画出来是一样的形状（折线的上下沿只是当天自己的最高/最低）。它同时会参与纵轴范围的计算，所以整天都在昨收下方时，那条线也不会被挤到画面外。
- **没有实时推送**（和自选列表同一条省额度的取舍）。分时不会自己刷新，**关一下再点开就是重新取最新**。
- **取不到时会自动再要一次**（只此一次）：富途在空闲一阵后的第一笔分钟线请求常会回一句没应答，紧接着第二笔就正常了，所以不必手动开关一回。
- 分时开着时主图的 `MA` 会换成 `均价` + `昨收`，关掉换回来；主图的缩放和右边空白也是借走再还的——回 K 线时拿回你原来的密度和位置，不会留一张密到看不懂的蜡烛图、也不会多出一段莫名其妙的空白。
- 分时和 1 分钟蜡烛**共用同一桶画线**（画线按「标的 + 周期」分桶，分时用的就是 1m 这一桶）。这是有意的：分时不是一种新周期，不该另起一份存量。
- **分时的副图默认只有「成交量」**，不再固定挂一条 MACD：一个交易日只有几百根分钟线，MACD(12,26,9) 光预热就要吃掉 30 多根，盘中刚开盘那阵子那块面板本来就是空的（很容易被当成「图没加载完」）。要加别的副图用工具条的 **「副图指标」**，分时想要什么自己挑（§15.10）。
- 你最后看的标的、周期、以及是否停在分时上，都会被记住，刷新后回到原地；副图组合同样记住，而且**分时与 K线各记一份**，互不覆盖。

### 15.3 自选列表（左侧栏）

- 默认 6 个：贵州茅台、平安银行、宁德时代、腾讯、AAPL、BTC/USDT
- 点一行 = 切图；行上显示最新价与涨跌幅（红涨绿跌）
- **添加**：用 §15.1 那个联想框；**删除**：行上的删除；**刷新**：手动刷新按钮
- **没有自动轮询**（故意：保护上游数据额度）。要看实时价就点刷新。
- 列表存在浏览器本地，换浏览器/清缓存会回到默认 6 个。

### 15.4 画线

工具栏上六个工具，`点击次数` 决定成图方式：

| 工具 | 怎么用 |
|---|---|
| 趋势线 | 点两点 |
| 射线 | 点两点（向一端无限延伸） |
| 水平线 | 点一下 |
| 价格线 | 点一下 |
| 斐波那契 | 点两点 |
| 画笔 | 按住拖动，**双击**结束 |

通用规则：

- **画到一半想放弃**：按 **Esc**（半途的点和当前工具一起取消，否则图会一直等你的下一个点）
- **第一下点在哪个图，线就归哪个图**：主图或任意副图都可以画；副图指标被关掉时，它的线会被**暂存**，重新挂载那个指标时线会自己回来
- 线画好后可以直接**拖动**端点或整体移动；改动会自动存下来
- 刷新页面后所有线原样回来（含你改的颜色、锁定、隐藏状态）

### 15.5 画线清单与样式

工具栏上的 **清单 · N** 按钮打开清单面板（N 是当前标的+周期上已画的条数，0 时按钮不可点）：

- 每行 = 中文名 + 时间 + 价位 + 点数 + 两个开关。例：`趋势线 09-04 08:00 → 09-08 08:00 · 1336.33 → 1295.91`
- **点一行** = 在图上选中这条线（再点同一行取消选中）。选中后可以直接改 **颜色 / 线宽 / 虚实**，只作用于这一条
- **锁定**：`锁定后拖不动这条线（右键仍可删）`——它防的是误拖，不是只读
- **隐藏**：这条线不画也点不到，但**没被删**，清单里那一行还在，随时可显示
- **删除**：从图上与存储里去掉
- 空态：`当前标的与周期上还没有画线`

小提示：切换周期或标的会换一整套画线（画线是按「标的 + 周期」分桶存的）。

### 15.6 画线的导出 / 链接 / 导入

- **导出** → 存成 `.json` 文件（含样式与锁定/隐藏），文件名形如 `vt-drawings-600519.SH-1D-2026-09-06.json`
- **链接** → 生成一条可直接发给别人的分享链接（已压缩，6 条线约 400 多字符）。剪贴板不可用时会摊出一个只读输入框让你手动全选复制
- **导入** → 选文件，**合并**进当前标的与周期（不是覆盖）。对方打开你发的链接会自动导入

导入的坏消息不会整体失败：提示会写成 `导入 3 条画线到 600519.SH|1D；重复 1 条未加；跳过 2 条；文件来自 000001.SZ|1D`，鼠标停在提示上能看到「第 N 条：原因」的明细。

### 15.7 指标公式（右侧抽屉）

工具栏 **ƒ 指标公式 · N**（N = 已保存条数）打开抽屉。可以写自己的指标，也能直接用**内置模板**（12 个：主图 5 个 —— EMA 双线 / 布林带 / 唐奇安 / VWAP / ATR 通道；副图 7 个 —— RSI / 金叉信号 / CCI / 威廉 %R / ROC+信号 / AO / MFI）。

迷你公式语言的要点（不需要编程基础也能写）：

```text
// 一行一条赋值，结尾加分号；// 或 # 后面是注释
中轨 = MA(close, 20);
上轨 = 中轨 + 2 * StdDev(close, 20);
return { 中轨, 上轨 };
```

- 每行 `名字 = 表达式;`，可以引用上一行的名字
- 最后一行 `return { 线名: 表达式 }` 决定画哪几条线
- 支持中文标识符；算术是按 K 线逐根算的
- 没有循环语法，所以不可能把自己卡死；写错了会报**带行号**的错误
- 保存时选 **主图** 还是 **副图**，可 启用/停用/删除；这些开关在工具条「副图指标」那一行的「自定义脚本」区里也能直接拨（见 §15.10），写公式仍然只在这里写。

公式存在浏览器本地，换设备不会跟过去。生产环境禁止浏览器执行任意代码，所以这里是自带解释器在算，不是把脚本扔给浏览器——这也意味着**它只认列出来的函数名**，别指望写外部代码。

### 15.8 脚本工作台（Pine 兼容层）

图表下方/侧面的工作台里有几个标签：**编辑器**、**脚本库**、**筛选器**、**导入导出**、**回测报告**。

- **编辑器**：写 TradingView Pine 风格的公式与策略，本项目的兼容层会把它翻译成可执行的信号（不是编译，是逐 bar 执行）
- **脚本库**：保存与复用你写过的脚本
- **筛选器**：脚本 + 标的池做条件扫描（`筛选 → 因子研究 → 回测 → 风险审计` 这条流水线的入口之一）
- **导入导出**：脚本文件与分享链接

两种分享链接**互不通用**，别弄混：

- `?s=…` = **脚本**分享
- `?d=…` = **画线**分享

### 15.9 数据与额度的实际约束

见 §18。**最要紧的一条**：别在图上挂一堆 1 分钟线轮询，富途的 K 线额度是按「每 7 天多少个标的」计的。

**分时也算在这本账上**：点亮一次 `分时` = 发一次 800 根分钟线的请求（约两个交易日，得多要一点才顺手够到昨收）。这就是它**故意不往左翻页**的原因——每拖一次就再吃一次额度，而换来的不是这张图要的东西。

### 15.10 副图指标（工具条 **副图指标 · N**）

`N` 是当前视图下面挂了几条副图。点开是一行管理条，三个动作就够：**加**（在下面目录里点一个）、**换**（某条副图上的「换」→ 再点目录里的目标指标，一步到位）、**关**（那条副图上的 `×`）。右上角「恢复默认」只重置**当前这个视图**。

- **分时与 K线各记各的**：两套选择分开存在浏览器本地，切视图就是切清单，不会互相覆盖。默认值也不一样——**分时默认只有「成交量」**（一天只有几百根分钟线，MACD 光预热就要吃掉 30 多根，盘中更是整块空白），**K线默认「成交量 + MACD」**（就是以前那个固定搭配，这次只是变成可改）。
- **目录里 19 个内置指标**：成交量 / MACD / KDJ / RSI / WR / BIAS / CCI / DMI / VR / OBV / PSY / ROC / MTM / TRIX / BRAR / CR / DMA / EMV / AO。已经挂上的那几个在目录里是灰的（鼠标停在上面写着「已在图上」），不会重复挂一份。
- **最多 6 条**。到数后目录里没挂上的按钮直接点不动（禁用态），得先关掉一个再加；而**「换」到数仍然可用**（换是一关一开，名额没变）。主图有保底高度，副图太多时是每条被压扁并出一个「副图过多，主图仅 Npx」提示条，不是主图看不见。
- **「换」会把新指标放到最下面**，而不是原地替。副图面板的地址是按它上面挂的指标算出来的（画线的「归哪条副图」就靠这个地址，§15.5），原地换会让一个叫 `sub:MACD` 的面板跑着 RSI，那些归属标注从此说谎。
- **关掉一条副图不会丢画线**：属于它的线被暂存进清单尾部，重新加回同一个指标时（面板地址一样）线会自己回到那块面板。
- **自定义公式出现在同一行的「自定义脚本」区**，在那里是开关而不是编辑器（写公式仍要去 §15.7 的工作台）。它们**不计进上面那 6 个名额**，也不会被「恢复默认」或目录里的加减操作删掉；反过来也一样：换副图不吃你的脚本，关脚本也不改副图清单。
- 副图高度可以拖分隔条微调：**副图组合不变时**（也不改窗口大小）你拖过的高度不会被程序改回去；一旦加减了副图或改了窗口大小，整排高度会重新算一次。
- 主图上的 `MA`（分时上换成均价 + 昨收）和自定义公式的**主图**叠加不在这张清单里，也不会被它关掉——那是另一套归属，两边不打架。

## 16 报警（侧栏 **Alerts**）

让你**在任何已经看消息的地方**收到价格/持仓/账户条件触发的通知。

（这个页面的字段标签目前是英文，因为刻意没动官方语言包。对照表见本节末。）

### 16.1 一条规则要填什么

| 字段（界面英文） | 中文含义 | 说明 |
|---|---|---|
| `Rule id` | 规则编号 | 自己起，短横线小写，例 `moutai-breakout` |
| `Watches` | 盯什么 | 四类：`market` 行情 / `position` 持仓 / `account` 账户 / `event` 外部事件 |
| `Symbol` | 标的 | 支持 §15.1 的代码联想；占位提示 `600519.SH / 茅台` |
| `Label` | 显示名 | 推送消息里出现的那句话 |
| `Condition` | 比较方式 | 空/非空、真值、大于、小于、**上穿**、**下穿**、上升、下降 |
| `Series` | 算哪条序列 | K线原始列（收盘/开盘/高/低/量/涨跌幅）+ 技术指标（RSI、MACD、BOLL 等） |
| `Level` | 阈值 | 和 `rhs`（另一条序列）二选一 |
| 周期 | 用哪档数据 | `1m / 5m / 15m / 30m / 60m / 1D` |
| 复权 | 前复权/后复权/不复权 | A 股建议保持一致 |
| `Severity` | 严重级别 | `info` / `warning` / `critical` |
| 冷却 | 多久之内不再重复发 | 防止一夜刷屏 |

`market` 类填标的 + 条件即可；`position` / `account` 类需要先有券商只读连接（§10）；`event` 类**不轮询**，只等外部往里推（见 16.3）。

### 16.2 保存之前先试一次

规则列表每行都有 **试跑**（dry run）：只算条件成不成立、不发消息、不改规则状态。**先试跑再启用**，是唯一能确认「这条规则真的能触发」的办法。

页级按钮 **立即运行** 可以带着「是否真的投递」跑一遍全量规则——用来验证通道通不通。

### 16.3 让 TradingView 把信号推过来

`event` 类规则保存的**那一瞬间**，页面会摊出完整的 Webhook 地址（形如 `/alerts/webhook/tv-push?key=…`）：

> `Paste this into TradingView's alert "Webhook URL". The secret is stored only as a hash, so this is the one chance to copy it.`

也就是说：**当时不复制，之后就看不到了**（库里只存哈希）。只能删掉规则重建。

### 16.4 消息发到哪（IM 通道）

报警复用本项目已有的 IM 通道层。配置路径：

1. 依赖：对应通道要装包（**设置 → IM 通道** 里缺哪个会直接把命令写给你，例如 `pip install 'vibe-trading-ai[telegram]'`）
2. 凭据：写在 `~/.vibe-trading/agent.json` 的 `channels` 段（这是用户状态目录，不在仓库里）
3. 开关：`VIBE_TRADING_ENABLE_SCHEDULER` 控制后台轮询是否随服务启动；也可在 **设置 → IM 通道** 手动 **启动通道**

每条规则可以指定发给哪个通道与目标（chat id）。没配通道时试跑会明确报 `xxx: not configured`，而不是静默不发。

### 16.5 必须知道的三件事

1. **后端进程活着才有报警。** 关掉黑色窗口，轮询就停了；这不是云服务。
2. **休市判定只按工作日。** 法定节假日目前不维护专门日历——因为休市日数据不变，`上穿/下穿` 这类条件天然不会误触发。
3. **别配 1 分钟轮询。** 会很快吃满行情额度（§18）。日线/15 分钟是合理档位。

## 17 TV 图表（`/tv-chart`）

嵌入 TradingView 官方免费小部件，**数据走 TradingView 的公开服务器**，和你本机的行情源、额度完全无关。

用途就是「拿 TradingView 的原生交互快速看一眼」。要从本项目里出报告、画可保存的线、写自己的指标，请用 **专业图表**（§15）。它不进侧栏，需要时地址栏输 `/tv-chart`。

标的框同样支持代码联想，占位提示 `600519.SH / 茅台 / NASDAQ:AAPL`；带市场前缀的写法（`NASDAQ:AAPL`、`SZSE:000001`）会被原样透传给小部件，不会被候选顶替。

## 18 行情数据从哪来、额度与限流

### 18.1 优先级

A股 / 港股 / 美股的取数链是**本机实际权限优先**：

1. 检测到本机 **FutuOpenD** 就绪 ⇒ 先问富途
2. 富途不可用（没开客户端、没权限、额度用完、连续失败被熔断）⇒ 自动降级到公开源（akshare / 新浪 / 腾讯 / yfinance 等回退链）

整个过程不需要你配置，界面上会显示这次走的哪条路。

### 18.2 富途那边的硬限制

| 限制 | 数值 | 后果与应对 |
|---|---|---|
| 历史 K 线额度 | 按「**每 7 天 N 个标的**」计（本机显示 `0/1000`） | **日线与分钟线都算在这里**——分钟线现在也优先走富途了。已经在本机 `agent/.env` 打开 `VIBE_TRADING_DATA_CACHE=true` 省额度；批量扫描（筛选器）选分钟周期时会逐标的发一次富途请求，扫 200 个就是 200 次。批量请用日线 |
| 快照 | 60 次 / 30 秒 | 自选列表不做自动轮询的原因 |
| 免费档历史长度 | 只有约 7 天 | 日线的长历史会自动走公开源补齐；分钟线往回翻超出范围就停在边界（港股/美股没有第二个分钟源） |
| A 股权限 | 按 **OpenD 登录 IP** 判境内/境外 | 人在境外时用 VPN 反而可能整体取不到 A 股数据 |

### 18.3 富途没开时会怎样

不是错误，是**变慢变浅**：首次连不上会被记一笔并在一小段时间内不再重试（免得每笔请求都去敲一次门），期间所有请求直接走公开源；之后再做一次探测，客户端一开就自动接回来。

**代码名册（§15.1）不占 K 线额度**——它用的是富途的「上市目录」接口，全量拉一次约 18 秒，之后靠本地缓存（默认 7 天保鲜）。

## 19 常见问题

**Q：侧栏点不进去 / 找不到某个功能。**
A：`/tv-chart`、`/compare`、`/about` 这三个页面**故意不进侧栏**，地址栏直接输。另：官方更新偶尔会挪入口，找不到时先看 §5 的表。

**Q：代码框没有下拉候选。**
A：三种可能。① 后端刚重启 → 显示 `代码库首次构建中…`，等十几秒再打字；② 打的是加密/外汇（`BTC-USDT` 等），名册里本来就没有，直接敲完整码回车；③ 后端窗口挂了 → 顶部会有断连横幅。

**Q：Alerts 页面是英文的？**
A：对，是刻意的。它的界面文案写在页面代码的默认值里，没有动官方那 8 套语言包（改了每次同步上游都会冲突）。对照表见 §16.1。

**Q：专业图表看港股/美股分钟线，报“只有一个源、它没应答”。**
A：分钟线现在优先取 FutuOpenD（四类股票都覆盖）。这句话的意思就是 OpenD 没在跑或者没登录——把它起来再刷新即可；A 股不用管，它会自动落回新浪。如果你看到的是“FutuOpenD covers HK/SH/SZ/US”，那是你切的标的不在这四类里（加密/英股/指数），开 OpenD 也没用。

**Q：周线怎么少了几周？/ 周线月线为什么翻不到上市第一天。**
A：都不是坏了。① **整周休市就没有那一周的线**（春节、国庆黄金周常出现，相邻两根隔 14 天甚至更久）；一周里第一个有交易的交易日才是那根的开盘日，所以节假日后那根常从周二/周四开始。② 周线/月线是把**日线**按自然周/自然月折出来的，能翻多远就等于日线能翻多远：富途链约 20 年（茅台周线到 2006-08）、公开链更短（港股实测只到 2019-11）、加密货币就是它日线的全部历史。状态行里的 `+1W` / `+1M` 就是在说“这些线是折出来的”（§15.2）。

**Q：分时的线拖不动 / 均价和交易所口径差一点 / 分时不自己刷新。**
A：三条都是设计，不是坏了。① 分时只取最近一个交易日，往左翻页要逐次发请求，会白白吃富途额度（§15.9），所以直接掐掉；要历史就点周期按钮回 K 线。② 均价是 Σ(收盘×成交量)/Σ(成交量) 的估算，而本项目的分钟线接口只回传 OHLCV 几列（富途原始返回里的成交额没被带过来），所以它不是交易所的 VWAP，差几个 tick 属正常。③ 分时没有实时推送，关一下再点开就是重新取最新。另外状态条写 `昨收未知` 时是**算不出涨跌幅**，不是平盘——界面上也不会印 `+0.00%`。还有一条：盘中开盘不久根数少，右边会空一段（那是今天还没走到的分钟，§15.2）——线应该是从**左边 09:30 就开始**的；如果你看到的是线从画面中间开始、左边空着三分之一，那是旧版本的问题，刷新一次就好。

**Q：分时下面怎么只有一条成交量？/ 我换上去的副图为什么跑到最下面了。**
A：前者是新的默认值（§15.10）：一个交易日只有几百根分钟线，MACD(12,26,9) 光预热就吃掉 30 多根，盘中那块面板本来就是空的，所以分时默认只留成交量那一条；要加别的用工具条的「副图指标」，K线那套默认仍是成交量 + MACD，两套各记各的。后者是必须的：副图面板的地址按它上面挂的指标命名，画线的「归哪条副图」靠这个地址认路，原地替换会让地址指向一个已经不在那儿的指标。

**Q：画的线不见了。**
A：先确认标的与周期——画线按「标的 + 周期」分桶。再看是不是被 **隐藏** 了（清单里那一行还在，点显示即可）。副图的线要在该副图指标挂载时才会回流。

**Q：重启之后所有画线/自选/自定义指标都没了。**
A：它们存在**浏览器本地**（不是服务器）。换了浏览器、清了站点数据、或者用了别的机器，就回默认值。要长期保留，用工具栏 **导出** 存成文件，或 **链接** 发给自己。

**Q：智能体不回话 / 一直转圈。**
A：多半是模型没配或超时。看后端黑窗口里的报错；把 **设置 → 超时（秒）** 调大；确认 `agent/.env` 里的 Key 与模型名对得上。

**Q：明明到价了却没收到报警。**
A：按顺序查：规则是否 **启用** → 后端窗口当时是否开着 → **试跑** 这条规则是否判为满足 → 冷却时间是否还没过（原因会写成 `3h59m 后可再发` 这种可读文本）→ **设置 → IM 通道** 里目标通道是否已启动。

**Q：接口报「额度已用完」。**
A：富途历史 K 线额度吃满。关掉密集轮询，确认 `VIBE_TRADING_DATA_CACHE=true`，等 7 天窗口滚动，或者暂时用公开源（关掉 FutuOpenD 即可强制走公开链路）。

**Q：打开 :8000 看到的界面和 :5899 不一样。**
A：`:8000` 是上一次 `npm run build` 的产物，不会自动更新。日常请用 `:5899`。

**Q：图上出现一句在本说明里查不到的英文报错（例如「minute bars are only supported for .SH/.SZ」）。**
A：那是**旧后端进程**说的，不是当前代码说的。`npm run build` 会把 `:8000` 的**界面**就地换成新版（静态文件逐请求读盘），而 `python api_server.py` **没有热重载**，接口还是改动前那份 ⇒ 新界面去问旧接口，旧接口答一句早已被删掉的文案。判据很简单：**这句话在 §15 / §19 里找不到**就是版本错位，关掉后端黑窗口重开即可（或 `start.bat`）。同理，改了后端而没重启，你看到的也是旧行为。

**Q：Windows 上命令行有红字/乱码。**
A：中文输出要先把控制台切到 UTF-8（`chcp 65001`，脚本里已经做了）。个别测试在中文 Windows 上会因编码默认值失败，那是已知的上游测试问题，不影响你使用。

**Q：改了前端代码，界面没变。**
A：`:5899` 会热更新，没变说明改的不是它引用的文件，或者前端窗口已经报错退出——去前端黑窗口看最后几行。

## 21 怎么用最顺手（推荐用法）

**日常盘前 5 分钟**

1. `start.bat` → 打开 `:5899`
2. **专业图表** 看自选（点行切换，要新价就点刷新）
3. 关心的价位在 **Alerts** 建规则 + **试跑** 一次
4. 要研究具体问题，回 **智能体** 丢一句话，结果去 **报告** 里翻

**省事的小习惯**

- 找代码别再敲全名：打 `600`、`茅台`、`aapl` 前几位选就行（§15.1）
- 画完重要支撑阻力，**导出** 一份 json 存进网盘——它只存在浏览器里
- 比较两个策略永远用 **报告 → 对比**，用差值列说话
- 让智能体跑长任务时，**停止生成** 就在输入框旁边，跑偏立刻掐
- 温度保持 0–0.2，别为了「更聪明」调高
- 富途开着的时候取数明显快，但**别挂 1 分钟轮询**（§18.2）
- 只想看今天怎么走的，用专业图表的 `分时`（§15.2）——一天的形状比 1 分钟蜡烛好读，而且它一次只发一个请求、不往左翻页
- 副图不要看不过来：工具条「副图指标」里挑自己真看的两个就够（§15.10），分时和 K线各记一份，不用来回改
- 这份说明会随功能更新——每次同步上游后如果界面变了，回来看看 §5 有没有新的

**什么时候不该用它**

- 需要 7×24 无人值守报警：本机进程模式做不到，要 Docker 常驻 + 密钥保护（§20）
- 需要毫秒级/盘口级实盘风控：这里的数据额度与轮询节奏是给研究用的，不是给执行用的
- 需要可审计的多用户身份：当前鉴权是「一把共享密钥 / 本机免鉴权」，无法把操作归因到具体某个人
